# 个人网站设计文档

## 概述

一个多合一个人网站，融合职业展示、作品/项目展示、博客/内容平台三大功能，采用 Galgame 视觉风格 + 苹果液态玻璃质感，支持白天/夜晚场景切换。

## 目标用户

- 招聘方 / 客户（查看能力和作品）
- 技术社区同行（阅读博客、交流）
- 朋友 / 粉丝（了解个人）

## 视觉系统

### 白天主题（Day Mode）

| 元素 | 取值 |
|------|------|
| 背景渐变 | `#E8F4FD` → `#FFF0F5`（天空蓝 → 樱花粉） |
| 毛玻璃卡片 | 白色半透明，`backdrop-blur: 20px`，边框 `rgba(255,255,255,0.6)` |
| 主文字 | `#1A1A2E`（深海军蓝） |
| 次要文字 | `#5A5A7A`（灰蓝） |
| 强调色 | `#FF6B9D`（樱花粉）、`#4FC3F7`（天空蓝） |
| 导航栏 | 悬浮毛玻璃条，`backdrop-blur: 24px`，圆角 20px |

### 夜晚主题（Night Mode）

| 元素 | 取值 |
|------|------|
| 背景渐变 | `#0D0D2B` → `#1A1A3E`（深夜蓝 → 紫罗兰） |
| 毛玻璃卡片 | 深蓝半透明，`backdrop-blur: 20px`，边框 `rgba(255,255,255,0.1)` |
| 主文字 | `#F0F0FF`（暖白） |
| 次要文字 | `#9999BB`（淡紫灰） |
| 强调色 | `#FFB347`（暖琥珀）、`#7B68EE`（紫罗兰） |
| 导航栏 | 深蓝毛玻璃条，内发光效果 |

### 动效规范

- 主题切换：0.6s 平滑渐变过渡（CSS transition）
- 卡片悬停：translateY(-4px) + 阴影增强 + 光晕略增
- 页面滚动入场：fade-in-up，延迟阶梯式 0.1s
- 背景粒子：樱花花瓣（白天）飘落动画 / 星星闪烁（夜晚）
- 主题切换按钮：缩放弹跳反馈

## 页面结构

### 全局布局（所有页面共用）

- **顶部导航栏**：悬浮毛玻璃条，包含 Logo / 品牌名、导航链接（首页、作品、博客、联系）、昼夜切换按钮
- **底部 Footer**：极简版权信息 + 社交链接图标 + 昼夜切换快捷入口

### 🏠 首页（/）

**首屏（Hero Section）**
- 左侧：二次元角色立绘占位图（玻璃框包裹，圆角 24px）
- 右侧：
  - 大标题：「你好，我是 [你的名字]」
  - 副标题：一句话介绍身份/方向（如「全栈开发者 · 热爱创造有趣东西的人」）
  - 两个玻璃按钮：「看看我的作品」→ /projects、「了解更多」→ 向下滚动
- 右上角：昼夜切换开关（月亮/太阳图标）

**以下区域（滚动后可见）**
- 技能标签云：圆角玻璃标签，按类别分组
- 精选项目预览：2-3 张玻璃卡片，点击跳转项目详情
- 最新文章预览：2-3 篇最新博客卡片

### 🎨 作品集（/projects）

- 页面标题：「我的作品」
- 筛选栏：按技术栈/类型过滤（玻璃下拉按钮）
- 网格布局：2-3 列响应式，每个项目一张玻璃卡片
  - 卡片内容：项目封面图 + 项目名称 + 简短描述 + 技术标签
- 点击卡片进入项目详情（独立页面 /projects/[slug]）

### 📝 博客（/blog）

- 页面标题：「我的文章」
- 顶部搜索框：玻璃输入框，按标题/标签搜索
- 列表布局：每篇文章一张玻璃卡片
  - 卡片内容：文章标题 + 摘要 + 发布日期 + 分类标签
- 分页或无限滚动
- 点击进入文章详情（/blog/[slug]，Markdown 渲染）

### 📬 联系（/contact）

- 左侧玻璃卡片：
  - 头像占位图（圆形）
  - 姓名 + 一句话简介
  - 社交链接图标（GitHub、Twitter/X、LinkedIn 等）
  - 邮箱地址
  - 「下载简历」按钮
- 右侧玻璃表单：
  - 姓名输入框
  - 邮箱输入框
  - 留言文本域
  - 发送按钮
- 提交成功后显示确认状态（玻璃成功提示框）

## 技术架构

### 框架与工具

| 技术 | 用途 |
|------|------|
| Next.js 15（App Router） | 路由、SSG/SSR、SEO |
| React 19 | UI 组件库 |
| Tailwind CSS 4 | 样式系统 |
| Framer Motion | 动画（主题切换、卡片悬停、页面过渡） |
| next-themes | 主题状态管理（自动跟随系统 + 手动切换） |
| Contentlayer / MDX | 博客内容管理（Markdown → 页面） |
| lucide-react | 图标库 |
| TypeScript | 类型安全 |

### 博客内容管理

- 文章以 Markdown 文件存放在 `content/blog/` 目录
- 每个文件包含 Frontmatter（标题、日期、标签、摘要等元数据）
- 构建时自动生成页面，无需搭建后台
- 支持代码高亮、图片引用、嵌入式内容

### 站点配置（lib/config.ts）

```typescript
export const siteConfig = {
  name: '你的名字',
  title: '你好，我是[你的名字]',
  subtitle: '一句话介绍',
  avatar: '/images/avatar-placeholder.png',
  social: {
    github: 'https://github.com/yourname',
    twitter: 'https://twitter.com/yourname',
    linkedin: 'https://linkedin.com/in/yourname',
  },
  email: 'your@email.com',
}
```

## 非功能性需求

- **响应式**：支持桌面（≥1280px）、平板（768-1280px）、手机（<768px）
- **性能**：首屏加载 < 2s，图片懒加载
- **SEO**：Meta 标签、Open Graph、结构化数据
- **可访问性**：键盘导航、ARIA 标签、对比度达标
- **PWA**：可选，支持离线访问和添加到主屏幕
