# 欢迎来到我的博客

这是第一篇示例文章。你可以在这里写下任何你想分享的内容。

## 如何使用

在 `content/blog/` 目录下创建一个新的 Markdown 文件，文件名就是文章的 slug。

### Frontmatter 格式

```yaml
---
title: "文章标题"
date: "2024-01-15"
excerpt: "文章摘要"
tags: ["标签1", "标签2"]
---
```

### 正文内容

使用标准的 Markdown 语法编写文章内容。
