## 项目简介

「时光记忆」是一个**微信小程序**，主要用来记录生活，并生成简单的 **Vlog**。

它还支持把**朋友圈里发布的内容导入进来**，方便集中整理已有素材，快速做出属于自己的生活记录短片。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 📝 记录生活 | 日常随手记，内容沉淀在小程序里 |
| 📥 导入朋友圈 | 支持导入朋友圈已发布内容，不用重新搬运 |
| 🎬 生成 Vlog | 把素材整理成简单的短视频，留住时光 |
